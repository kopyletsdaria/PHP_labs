## Структура проєкту

*   `classes/Task.php` - базовий клас завдання із захищеними (`protected`) властивостями.
*   `classes/RecurringTask.php` - похідний клас (успадкування), який додає інтервал повторення.
*   `classes/ProjectBoard.php` - клас-менеджер, який зберігає колекцію завдань і керує ними.
*   `lib/functions.php` - бібліотека із допоміжними функціями форматування дати та перевірки дедлайну.
*   `index.php` - головний файл, де створюються об'єкти та виводиться HTML-таблиця.
*   `style.css` - файл стилів.

## Реалізовані вимоги

1. **Підготовка структури**: код розділено на логічні частини. Класи лежать у папці `classes/`, звичайні функції - в `lib/`.
2. **Базовий клас (`Task`)**: створено клас із властивостями `title`, `dueDate`, `priority`, `done`. Вони приховані від прямого доступу. Написано конструктор та метод `getInfo()`.
3. **Похідний клас (`RecurringTask`)**: створено клас, який розширює `Task` через `extends`. Додано нову властивість `repeatInterval`. Метод `getInfo()` перевизначено з використанням `parent::getInfo()`.
4. **Клас-менеджер (`ProjectBoard`)**: містить масив завдань. Реалізовано методи для додавання нових завдань (`addTask()`), отримання списку невиконаних завдань (`pendingTasks()`) та позначення завдання як виконаного (`markDone()`).
5. **Бібліотека функцій**: створено дві функції: одна для перетворення дати у зручний формат (`d.m.Y`), інша - для визначення простроченого дедлайну.
6. **Головний файл**: усі файли підключено через `require_once`. Створено кілька звичайних та повторюваних завдань. Дані успішно виводяться у браузері у вигляді HTML-таблиці з використанням методів об'єктів та бібліотечних функцій.

## Як запустити локально

Для перевірки роботи скрипта використайте вбудований сервер PHP:

1. Відкрийте термінал у головній папці `php_labs`.
2. Виконайте команду:

   ```bash
   php -S localhost:8000
   ```
