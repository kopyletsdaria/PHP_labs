# Практикум 2: Обробка форм, валідація, localStorage (Варіант 7)

**Виконала:** Копилець Дар'я, група ІО-44

## Структура проєкту

*   `form.php` - головний файл, де знаходиться сама форма, PHP-код для її обробки та трохи JavaScript.
*   `style.css` - файл стилів для оформлення сторінки.

## Реалізовані вимоги

1. **Підготовка структури**: створено папку з файлом `form.php`, який працює і як форма, і як обробник.
2. **Створення HTML-форми**: додано форму з методом `post` і полями для назви, дедлайну та пріоритету. Увімкнено базову перевірку засобами HTML5 (`required`, `type="date"`).
3. **Серверна обробка та валідація**: написано PHP-код, який ловить дані з `$_POST`. Перевіряється, чи не порожні поля, чи правильна дата і чи збігається пріоритет із дозволеним списком.
4. **Показ результату**: якщо користувач помилився, форма показує помилки, але введені дані не зникають (захищено через `htmlspecialchars()`). Якщо все правильно — виводиться зелене повідомлення про успіх.
5. **Клієнтська JavaScript-валідація**: додано просту перевірку на JS. Якщо назва коротша за 3 символи, вискакує `alert`, і форма не відправляється (`event.preventDefault()`).
6. **Робота з localStorage**: форма автоматично зберігає все, що ти вводиш, прямо в браузер. Якщо випадково оновити сторінку, дані не зникнуть. Після успішного додавання завдання ця чернетка сама очищується.
7. **Перевірка роботи**: усі перевірки протестовано — форма правильно реагує на порожні поля та неправильні формати, автозбереження працює.

## Як запустити локально

Для перевірки роботи скрипта використайте вбудований сервер PHP:

1. Відкрийте термінал у папці з проєктом.
2. Виконайте команду:

   ```bash
   php -S localhost:8000
   ```
