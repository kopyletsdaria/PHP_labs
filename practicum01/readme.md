# Практикум 1: Трекер завдань (Варіант 7)

**Виконала:** Копилець Дар'я, група ІО-44

Цей репозиторій містить рішення для першої практичної роботи з PHP. Проєкт реалізує трекер завдань відповідно до заданого варіанта предметної області та умов завдання.

## Структура проєкту
- `index.php` - головний файл, що містить логіку роботи з даними, функції та HTML-розмітку.
- `style.css` - файл стилів для візуального оформлення сторінки.

## Реалізовані вимоги 
1. **Підготовка структури**: створено робочу директорію з основними файлами проєкту.
2. **Оголошення масиву даних**: ініціалізовано масив із 4 записів, кожен з яких є асоціативним масивом із полями предметної області: `title`, `dueDate`, `priority`, `done`.
3. **Функція форматування**: написана функція зі строгою типізацією параметрів (`array`) та значення, що повертається (`string`), яка формує рядок з коротким описом завдання.
4. **Умовна логіка**: за допомогою конструкції `if/elseif/else` обчислюється статус кожного завдання:
   - «Виконано» (якщо властивість `done` — `true`);
   - «Прострочено» (якщо `dueDate` знаходиться у минулому часі відносно поточної дати);
   - «В роботі» (в усіх інших випадках).
5. **Виведення у вебсторінку**: дані виводяться у вигляді HTML-таблиці через цикл `foreach`. PHP-код інтегровано з HTML-розміткою із застосуванням функції форматування.
6. **Агрегатний показник**: за допомогою вбудованих функцій `array_filter()` та `count()` обчислено і виведено окремим блоком загальну кількість виконаних і невиконаних завдань.
7. **Перевірка результату**: на початку скрипта увімкнено виведення помилок (`error_reporting(E_ALL)`) для контролю якості коду.

## Як запустити локально
Для перевірки роботи скрипта використайте вбудований сервер PHP:
1. Відкрийте термінал у папці з проєктом.
2. Виконайте команду: 
   ```bash
   php -S localhost:8000
3. Відкрийте в браузері http://localhost:8000
