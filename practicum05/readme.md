# Практикум 5: Взаємодія фронтенду та бекенду (AJAX, JSON) (Варіант 7)

**Виконала:** Копилець Дар'я, група ІО-44

## Структура проєкту

*   `api_list.php` - JSON-ендпоінт для отримання списку завдань із підтримкою фільтрації.
*   `api_add.php` - ендпоінт (POST) для додавання нового запису в БД.
*   `api_done.php` - ендпоінт для оновлення статусу виконання завдання.
*   `index.php` - сторінка з порожнім HTML-контейнером та підключеним скриптом.
*   `script.js` - фронтенд-логіка (AJAX-запити, малювання DOM, обробка подій).
*   `db.php` - підключення до PostgreSQL (PDO).
*   `style.css` - файл стилів.

## Реалізовані вимоги

1. **JSON-ендпоінти**: створено скрипти `api_list.php` та `api_add.php`, які не виводять HTML, а повертають дані у форматі JSON (через `header('Content-Type: application/json')` та `json_encode()`).
2. **Завантаження через AJAX**: при відкритті сторінки `script.js` викликає `fetch('api_list.php')`, перетворює відповідь методом `.json()` та малює таблицю у порожньому контейнері `<tbody id="results">`.
3. **Жива фільтрація**: на подію `input` селекта пріоритетів викликається `fetch` з GET-параметром `?priority=...`. Контейнер перемальовується одразу, без перезавантаження.
4. **Додавання запису (AJAX)**: оброблено подію `submit` форми через `event.preventDefault()`. Дані передаються методом POST через `FormData`. Після успіху (перевірка `response.ok`) список оновлюється.
5. **Обробка помилок**: мережеві помилки перехоплюються через `try...catch` і виводяться у спеціальний блок `div` безпосередньо у DOM (а не лише в консоль).
6. **Вимога варіанта 7 (Чекбокси)**: реалізовано перемикання статусу «виконано» чекбоксом. При кліку JS надсилає запит на `api_done.php`, і рядок миттєво візуально позначається класом `done-row` (перекреслюється) без оновлення сторінки.
